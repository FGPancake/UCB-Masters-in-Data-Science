# MIDS 207 Final Project
Kaggle Competition: https://www.kaggle.com/competitions/fungi-clef-2025/overview

## Data
Unzip the data downloaded directly from the Kaggle competition and place it in the /data folder

OR cd into data folder and run this command: `kaggle competitions download -c fungi-clef-2025`

## Project Overview
Built a fungal taxonomic classification model using a convolutional neural net (CNN) trained on limited image data, supplementing the initial model with additional metadata input nodes, improving performance and partially correcting class imbalance issues in the dataset
