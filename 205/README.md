# MIDS 205 Final Project
Data Engineering final project for DATASCI 205

## Project Overview
We set out to create our own diversified stock portfolio to minimize risk exposure, analyzing stock data with a graph database. We first translate tabular data into nodes & relationships, allowing us to visualize relationships in graph form, then leverage native Neo4j algorithms to uncover correlations, clusters, and centrality of stock influence. We could then make recommendations and facilitate real-time updates (Redis) and dynamic schema changes with time (MongoDB).
